ROOT now comes as a standalone desktop application alongside the local browser version.

- **Windows x64:** NSIS installer and portable EXE.
- **Linux x64:** DEB installer and portable AppImage.
- Installed editions check for stable updates, download explicitly, save progress and restart for installation.
- Portable editions use manual updates and keep progress in `ROOT-data` beside the application.
- Both interfaces, offline progression, agents, AI hardware, incidents and underground expansion use the same simulation as browser mode.
- English/German desktop settings, an isolated renderer, stable storage origin and confirmed saving before closing or reloading.

Choose `-setup.exe` or `.deb` for installation; choose `-portable.exe` or `-portable.AppImage` for manual replacement. Keep `ROOT-data` when replacing portable. AppImage requires FUSE and permitted Chromium sandbox/user namespaces; use the DEB if your distribution restricts portable sandboxing.

**Moving from the browser:** export your JSON backup and import it in desktop Settings. Existing browser progress is not changed automatically. Desktop packages do not need a separately installed Node.js.

Preview packages are unsigned; Windows may display an unknown-publisher/SmartScreen prompt. `SHA256SUMS.txt` covers release assets. The updater validates SHA-512 against release metadata; this is not a signing certificate. See [desktop setup and update details](https://github.com/Tricade/root-network-os/blob/main/docs/desktop.md).
