# AI assistance disclosure

ROOT was developed with substantial generative-AI assistance, under human direction. That includes implementation, tests, documentation, translations, interface design, procedural geometry and asset-generator scripts. Parts of the supplied base asset package were created with AI assistance as described by its supplier.

This is a disclosure of the development process, not a guarantee that generated code or content is correct. Changes still need review, testing and clear provenance. Automated tests cover specific scenarios; they do not establish perfect behavior, exhaustive browser coverage or performance at the largest accepted save size. Contributors should describe any AI assistance and the verification they performed.

The bundled simulation does not call an AI provider, run an LLM or require an API key. Its agents, AI/GPU servers and workloads are simulated infrastructure. Saves and operating data remain local. The asset generators also run locally without calling an AI service or downloading models.

Asset and library licensing is component-specific. The supplied base package's ownership statements are retained as supplied evidence, rather than presented as independently verified authorship. See [NOTICE.md](NOTICE.md), the [asset-generator guide](tools/asset-generator/README.md) and the [current file inventory](asset-pack/docs/runtime_inventory.json).
